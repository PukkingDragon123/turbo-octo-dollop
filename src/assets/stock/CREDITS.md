# Stock images

Drop CC0 / public-domain photos here (`.jpg`, `.png`, `.webp`). `src/gfx/aged.js` bundles them automatically;
each one is addressable by its file name without the extension, e.g. `drawStockImage(ctx, 'office_1962', ...)`.
Until a file exists, every id falls back to a procedural photo (`proceduralPhoto`).

Only add images whose licence allows redistribution without attribution requirements that we cannot meet.
